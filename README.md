Netflix Clone

This project is a Netflix Clone built using HTML, CSS, and JavaScript.
It replicates the UI of Netflix, including the homepage with movie posters, hover effects, and responsive design.


---

Features

Netflix-style homepage layout

Movie poster grid with hover animations

Responsive design (desktop & mobile friendly)

Smooth scrolling & transitions

 Easy to customize



---

 Tech Stack

HTML5

CSS3 (Flexbox, Grid, Animations)

JavaScript (Vanilla / React if used)
